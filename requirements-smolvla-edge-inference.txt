# lerobot 0.5.2 (commit 052d3294) -- SmolVLA inference-only, edge deployment.
# Scope: load a checkpoint + run forward-pass inference. Excludes training,
# dataset loading/recording, PEFT, and robot-hardware extras (feetech, dynamixel, etc.).
# CPU-only: no GPU/CUDA required.
# Regenerate with: uv export --extra smolvla --no-dev --no-hashes --format requirements-txt
# then drop datasets/dataset-loading and accelerate (not imported by the inference path; see below).
#
# NOTE: this assumes x86_64. On ARM edge boards (Jetson/Tegra), standard PyPI
# torch/torchvision wheels generally do NOT install -- use vendor-provided
# wheels (or board-vendor-provided torch) instead of the lines below.
#
# =============================================================================
# ENVIRONMENT PREREQUISITES (not covered by this file -- must be provided by
# the base image / OS before `pip install -r` is run)
# =============================================================================
#
# - Python:        >= 3.12 (required by lerobot's pyproject.toml). This file
#                   does not install or select a Python interpreter.
# - pip:           must already be present in the image; this file assumes
#                   `pip install -r requirements-edge-inference.txt` can run.
# - Architecture:  x86_64 assumed (see ARM/Jetson note above).
# - glibc:         >= 2.28 (manylinux_2_28). torch, numpy, and opencv-python-headless
#                   ship manylinux_2_28 wheels; images built on musl (e.g. Alpine)
#                   or older glibc (e.g. CentOS 7 / manylinux2014-era systems)
#                   will NOT be able to install these wheels as-is and would
#                   require building from source instead.
#                   Verify with: ldd --version
# - libgomp:       OpenMP runtime required at import time by torch/numpy's
#                   underlying math kernels. Not a pip package -- must be
#                   installed via the OS package manager (e.g. `apt install
#                   libgomp1` on Debian/Ubuntu-based images). Missing this
#                   causes an import-time crash, not a pip install failure,
#                   so it's easy to miss until first run.
# =============================================================================
